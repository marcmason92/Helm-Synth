## 📖 About

Helm Synth is developed by Matthew Tyas and distributed as an open source project with builds for Windows, Linux and BSD style systems. It packs two oscillators with a large set of waveforms, a sub oscillator, a noise generator, two LFOs, two ADSR envelopes, a step sequencer, a formant filter, a stutter effect and a reverb unit into a single window. Recent builds tightened preset browsing, added more factory patches and improved the modulation workflow so that routing a source to a destination takes fewer clicks than before.

If you came looking for a Helm Synth download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Everything here is a community reference: the installer is fetched from the project distribution page, and this repository stores no binaries.

**Good for:** sound designers building patches from scratch · electronic music producers · film and game audio composers · students learning subtractive synthesis · live performers using a laptop rig · plugin users who want a standalone fallback · anyone migrating an old patch library to a modern machine

## 🔑 Features

| | |
|---|---|
| 🎛️ **Dual Oscillators** | Two full oscillators with a broad waveform set, detune, phase offset and per oscillator amplitude shaping. |
| 🧬 **Modulation Matrix** | Route any source, such as LFOs, envelopes, velocity or the step sequencer, to almost any parameter. |
| 🎚️ **Formant Filter** | A vowel style filter with morphing between vowel positions for vocal and talking textures. |
| 🥁 **Step Sequencer** | A built in 16 step sequencer that can drive pitch, filter cutoff or amplitude in sync with tempo. |
| 🌊 **Effects Chain** | Stutter, delay and reverb stages that can be reordered and blended inside the same patch. |
| 🎹 **Standalone and Plugin** | Runs on its own for quick ideas and loads into a host as a VST or LV2 instrument. |
| 📦 **Preset Browser** | Tag based browsing with factory patches plus room for your own saved sounds. |
| ⌨️ **MIDI Learn** | Map hardware knobs and faders to interface controls without leaving the synth window. |
| 🖥️ **Scalable Interface** | Resizable window that keeps controls readable on high DPI displays and small laptop panels. |

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without a message | Confirm the downloaded file finished transferring, then run it again from a local folder rather than a network drive. |
| No sound after launch | Check the audio device selected in the settings panel and confirm the correct output is chosen. |
| Plugin not listed in the DAW | Rescan the plugin folder in the host and verify the install path matches the one the host scans. |
| Crackling or dropouts | Raise the buffer size in the audio settings and close other applications using the sound device. |
| Patch sounds different from a demo | Some factory presets rely on the step sequencer, so start playback in the host to hear the full movement. |
| Interface looks tiny on a 4K screen | Increase the interface scale in the settings panel or raise the Windows display scaling value. |
